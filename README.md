# Agentic Self-Correcting RAG

This project provides a starter structure for an agentic self-correcting retrieval-augmented generation (RAG) system.

## Project Structure

- app/ - application entry points and orchestration
- config/ - configuration files
- data/ - raw, processed, and vector store data
- docs/ - documentation
- ingestion/ - data ingestion modules
- preprocessing/ - preprocessing logic
- embeddings/ - embedding generation components
- retrieval/ - retrieval pipeline
- agents/ - agent logic
- evaluation/ - evaluation utilities
- utils/ - shared helpers
- tests/ - tests
- notebooks/ - notebooks
- assets/ - static assets

## Getting Started

1. Create a Python virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python main.py
   ```
